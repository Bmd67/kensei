<div align="center">
  <h1>Kensei (剣聖)</h1>
  <p><em>The sword of the code warrior</em></p>
</div>

## Features
- Blazing fast Rust build tool
- File watching with auto-rebuild
- Project scaffolding from templates
- Test integration with filtering

## Usage
```bash
cargo install kensei
kensei build --release
kensei build --watch
kensei test
kensei init my-project
kensei clean
```
